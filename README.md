# 🎓 Sistema de Notas ESFE

Aplicación de escritorio en Java Swing para gestionar notas de estudiantes de la carrera de Software (Articulado) en ESFE.

## 🚀 Tecnologías

- Java 21
- Swing (GUI)
- SQL Server
- Maven
- Git / GitHub

## 📂 Estructura del Proyecto
SistemaNotasESFE/
├── docs/ # Documentación
├── sql/ # Scripts de base de datos
├── src/ # Código fuente
├── lib/ # Librerías (driver JDBC)
└── pom.xml # Dependencias Maven

## 🛠️ Instalación

1. Clonar repositorio
2. Configurar SQL Server con el script `sql/04-all-in-one.sql`
3. Abrir en IntelliJ
4. Ejecutar `Main.java`
